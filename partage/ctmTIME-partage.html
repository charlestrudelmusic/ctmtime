ctmTIME : partage

Un lien et un code QR par institution. Même app, adresse différente.

Lequel donner ? Le lien de l'institution à tes élèves ; le lien public à tout le monde (autres profs, site Wix). Les annonces de groupe ne s'affichent qu'avec le lien de l'institution.

Sur iPhone : les élèves doivent ouvrir le lien dans Safari (le code QR scanné avec la caméra le fait), puis Partager → Sur l'écran d'accueil.

Nouveau groupe : demande à Claude ; il crée le dossier, le code QR et met cette fiche à jour.
